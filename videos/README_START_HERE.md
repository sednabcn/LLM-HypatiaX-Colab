## 💡 Pro Tips

### For Best Results:

1. **Record in Order** - Do tutorials 1→2→3→4
   - Each builds on the previous
   - Files from earlier tutorials are used later

2. **Test First** - Before recording each tutorial:
   - Run through all commands
   - Verify outputs match script
   - Fix any issues

3. **Mistakes Are OK** - If you make a mistake:
   - PAUSE for 3 seconds (silence)
   - Restart the sentence
   - Continue
   - Edit out the mistake later

4. **Speak Slowly** - Talk 20% slower than normal
   - Viewers are following along
   - Gives time to see commands
   - Makes editing easier

5. **Show, Don't Just Tell**
   - Let viewers see the output
   - Pause after each command executes
   - Highlight important parts

6. **Keep It Real**
   - Minor imperfections are relatable
   - Don't spend hours editing
   - Authentic > perfect

## 🐛 Common Issues & Solutions

### Issue: "My terminal text is too small to read"
```bash
# Increase font size to 14-16pt
# In terminal preferences: Edit → Preferences → Font
```

### Issue: "Audio is too quiet"
- Move microphone 6-8 inches from mouth
- Increase gain in OBS Audio Mixer
- Use Audacity to normalize audio after recording

### Issue: "Video file is huge (>1GB for 10 min)"
```bash
# Compress with ffmpeg:
ffmpeg -i input.mp4 -vcodec libx264 -crf 23 output.mp4
```

### Issue: "I made too many mistakes"
- Normal! Options:
  - Edit them out (find 3-second pauses)
  - Re-record that section only
  - Or just leave them - it's authentic!

### Issue: "My system lags during recording"
- Close all other applications
- Lower OBS output resolution to 720p
- Reduce frame rate to 30fps
- Record to SSD if available
