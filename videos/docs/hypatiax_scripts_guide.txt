# HypatiaX Scripts - Quick Start Guide

Get your video tutorials and paper verification up and running in minutes.

## Installation (5 minutes)

```bash
# 1. Download scripts
cd ~/hypatiax  # or wherever your project is

# 2. Copy these files to your project:
#    - video_production_manager.sh
#    - paper_verification_manager.sh
#    - SCRIPTS_README.md (this file)

# 3. Make scripts executable
chmod +x video_production_manager.sh
chmod +x paper_verification_manager.sh

# 4. Install video tools (one-time setup)
./video_production_manager.sh setup

# Done! ✓
```


## Troubleshooting

### "Command not found"

```bash
# Make scripts executable
chmod +x *.sh
```

### "OBS not installed"

```bash
# Run setup again
./video_production_manager.sh setup
```

### "Results file missing"

```bash
# Run tests first
python standalone_v4.py --all --extrapolation \
    --output results/full_suite_results.json
```

### "Figure generation failed"

```bash
# Install dependencies
pip install matplotlib numpy scipy

# Try again
./paper_verification_manager.sh generate-figures
```
