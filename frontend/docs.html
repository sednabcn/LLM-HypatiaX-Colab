Complete guide to using HypatiaX

Getting Started

HypatiaX is an advanced Named Entity Recognition system designed for Tableau query processing.

Quick Start

  1. Navigate to the NER Demo
  2. Enter your Tableau query
  3. Select a mapping method
  4. Click "Extract Entities" to process

API Reference

Endpoints

Map natural language description to Tableau formula

  "description": "Sum of sales by year",
  "method": "vocab"
