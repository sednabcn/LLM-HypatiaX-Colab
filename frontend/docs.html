🚀 Getting Started

HypatiaX is an advanced AI-powered system that combines Named Entity Recognition (NER), Formula Mapping, and DeFi calculations.

Quick Start

  1. Formula Mapping: Navigate to Home to convert natural language to Tableau formulas
  2. NER Demo: Visit NER Demo to extract entities from text
  3. DeFi Calculator: Go to DeFi Calculator for impermanent loss analysis

Installation

# Clone the repository git clone https://github.com/yourusername/hypatiax.git # Install dependencies pip install -r requirements.txt # Start the backend server python app.py # Open frontend in browser open index.html

🎯 HypatiaX API

Convert natural language descriptions to Tableau formulas.

POST/api/hypatiax/map

Map a natural language description to a Tableau formula.

Request Body:
{ "description": "Calculate the total of Sales", "method": "vocab" // or "semantic" }
Parameters:
Parameter Type Description
description string Natural language query describing the calculation
method string Mapping method: "vocab" or "semantic"
Response:
{ "formula": "SUM([Sales])", "confidence": 0.95, "method": "vocab", "processing_time_ms": 45, "entities": [ { "text": "total", "label": "AGGREGATION", "start": 14, "end": 19 }, { "text": "Sales", "label": "FIELD", "start": 23, "end": 28 } ] }

GET/api/hypatiax/test

Run test suite with predefined sample queries.

Response:
{ "test_results": [ { "description": "Calculate the total of Sales", "formula": "SUM([Sales])", "status": "pass", "confidence": 0.95 } ], "passed": 8, "failed": 0, "total": 8 }

🔍 NER API

Named Entity Recognition for formula extraction and text analysis.

POST/api/ner/extract-formula

Extract mathematical formulas from text.

Request Body:
{ "text": "The quadratic formula is x = (-b ± √(b²-4ac)) / 2a", "domain": "general" // or "defi", "finance", "physics" }
Response:
{ "formula": "(-b ± √(b²-4ac)) / 2a", "domain": "mathematics", "confidence": 0.92, "latex": "x = \\frac{-b \\pm \\sqrt{b^2-4ac}}{2a}" }

POST/api/ner/recognize-entities

Recognize and extract entities from text.

Request Body:
{ "text": "Show me the sum of sales by region for last quarter" }
Response:
{ "entities": [ { "text": "sum", "label": "AGGREGATION", "start": 12, "end": 15, "confidence": 0.98 }, { "text": "sales", "label": "FIELD", "start": 19, "end": 24, "confidence": 0.95 }, { "text": "region", "label": "DIMENSION", "start": 28, "end": 34, "confidence": 0.93 } ], "processing_time_ms": 32 }

POST/api/ner/convert-to-latex

Convert formula to LaTeX format.

Request Body:
{ "formula": "E = mc^2" }
Response:
{ "latex": "E = mc^{2}", "domain": "physics" }

💎 DeFi API

Calculate impermanent loss and analyze liquidity pool positions.

POST/api/defi/il-percentage

Calculate impermanent loss percentage based on price change.

Request Body:
{ "initial_price": 2000, "current_price": 2400 }
Response:
{ "il_percentage": -2.02, "price_ratio": 1.2, "interpretation": "Moderate impermanent loss. Price increased by 20%." }

POST/api/defi/analyze-position

Complete analysis of a liquidity pool position including fees and ROI.

Request Body:
{ "initial_token_a": 10, "initial_token_b": 20000, "initial_price": 2000, "current_price": 2400, "daily_volume_usd": 500000, "pool_tvl_usd": 10000000, "days_elapsed": 30, "fee_rate": 0.003 }
Response:
{ "initial_value_usd": 40000, "current_position": { "token_a": 9.13, "token_b": 21912, "value_usd": 43824 }, "hodl_value_usd": 44000, "il_percentage": -2.02, "fee_income_usd": 600, "net_pnl_usd": 424, "pool_quality_score": 75, "daily_turnover_rate": 5.0, "days_to_breakeven": 15.2, "recommendation": "Good position. Fees are offsetting IL." }

POST/api/defi/quality-score

Calculate pool quality score based on volume and TVL.

Request Body:
{ "daily_volume_usd": 500000, "pool_tvl_usd": 10000000 }
Response:
{ "quality_score": 75, "daily_turnover_rate": 5.0, "rating": "Good" }
