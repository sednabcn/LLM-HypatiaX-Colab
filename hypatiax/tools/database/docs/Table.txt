Yes, it can be extended! The architecture is modular:
    1. Add new classes (TheGraphUniswapV3, TheGraphUniswapV4)
    2. Update manager to support version selection
    3. Handle version-specific features (ticks, hooks, fee tiers)
    4. Maintain backward compatibility with existing V2 code
The inheritance from DataSource makes adding new protocols (Curve, Balancer, Sushiswap) equally straightforward! 🎯
