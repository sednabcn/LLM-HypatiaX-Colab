Generate Formula Patterns
Extract operators (SUM, AVG, IF, CONTAINS, etc.), arguments ([Field Names]), and syntax elements
🔧 Method:
generation.py → gen_patterns_tableau_formulas()
📤 OUTPUTS:
patterns_tableau_formulas: Specialized pattern categories
Pattern Categories:
• ARG: Field names in brackets [Sepal Length]
• ARGN: Field names without brackets
• OPER: Tableau functions (SUM, AVG, IF, CONTAINS)
• NUM: Numeric values
• ADP: Comparison operators (>=, <=, !=, AND)
• ADV: Sorting keywords (ASC, DESC, NULL)
