🎮 How to Use the Demo
Option 1: Interactive CLI (Easiest)
bashpython demo/demo_interactive.py
Then select from menu:

1 = Description NER demo
2 = Formula NER demo
3 = Combined NER demo
4 = Compare all models
5 = Interactive typing mode
6 = Run all demos

Option 2: Web Interface (Visual)
bashpip install flask
python demo/demo_web_app.py

# Open browser to <http://localhost:5000>

Option 3: Programmatic
pythonfrom demo.demo_interactive import HypatiaXDemo

result = demo.run_example("calculate the sum of sales")
