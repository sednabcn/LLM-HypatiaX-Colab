# Vulnerability Fix Scripts - Usage Guide

This package contains two scripts to automatically remediate the 35 security vulnerabilities found in your Python environment.

## 📋 Files Included

1. **fix_vulnerabilities.py** - Full-featured Python script with advanced options
2. **quick_fix.sh** - Simple bash script for quick updates
3. **security_summary.md** - Detailed vulnerability report

## 🚀 Quick Start

### Option 1: Bash Script (Recommended for Quick Fix)

```bash
# Make it executable
chmod +x quick_fix.sh

# Update CRITICAL and HIGH priority packages with backup
./quick_fix.sh --priority --backup

# Update all packages with backup
./quick_fix.sh --backup

# Update all except major version upgrades (safest)
./quick_fix.sh --backup --skip-major
```

### Option 2: Python Script (More Control)

```bash
# Preview changes without making them
python fix_vulnerabilities.py --dry-run

# Update with backup and interactive prompts
python fix_vulnerabilities.py --backup --interactive

# Update only critical/high priority with testing
python fix_vulnerabilities.py --priority --backup --test

# Safe mode: skip major version upgrades
python fix_vulnerabilities.py --backup --skip-major
```

## ⚙️ Command Options

### Bash Script (quick_fix.sh)

| Option | Description |
|--------|-------------|
| `--priority` | Update only CRITICAL and HIGH severity packages |
| `--backup` | Create requirements backup before updating |
| `--skip-major` | Skip major version upgrades (safer) |
| `--help` | Show help message |

### Python Script (fix_vulnerabilities.py)

| Option | Description |
|--------|-------------|
| `--dry-run` | Preview changes without making them |
| `--priority` | Update only CRITICAL and HIGH severity packages |
| `--backup` | Create requirements backup before updating |
| `--test` | Run pytest after each update |
| `--skip-major` | Skip major version upgrades |
| `--interactive` | Prompt before each update |

## 📝 Recommended Workflow

### For Production Environments

```bash
# 1. Create a backup
./quick_fix.sh --backup --priority

# 2. Run your test suite
pytest
# or
python manage.py test

# 3. If tests pass, update remaining packages
./quick_fix.sh --backup --skip-major

# 4. Run tests again
pytest
```

### For Development Environments

```bash
# Preview all changes first
python fix_vulnerabilities.py --dry-run

# Update with interactive prompts
python fix_vulnerabilities.py --backup --interactive

# Or update all at once (faster)
./quick_fix.sh --backup
```

### For CI/CD Pipelines

```bash
# Non-interactive update with testing
python fix_vulnerabilities.py --priority --test
```

## 🔄 Rollback Instructions

If something goes wrong after updating:

```bash
# Restore from backup (created with --backup flag)
pip install -r requirements_backup_YYYYMMDD_HHMMSS.txt

# Or reinstall specific package
pip install package_name==old_version
```

## 🆘 Troubleshooting

### Permission Errors
```bash
# Use sudo if needed (not recommended in virtual environments)
sudo ./quick_fix.sh --backup

# Or activate your virtual environment first
source venv/bin/activate
./quick_fix.sh --backup
```

### Dependency Conflicts
```bash
# Try updating pip first
pip install --upgrade pip

# Then run the script
./quick_fix.sh --backup
```

### Package Not Found
If a package isn't installed, the script will skip it with a warning.
