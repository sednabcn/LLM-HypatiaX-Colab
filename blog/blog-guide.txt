Articles may be accompanied by online appendices containing data, demonstrations, instructions for obtaining source code, or the source code itself if appropriate. We strongly encourage authors to include such appendices along with their papers. Transactions on Machine Learning Research

YES! Absolutely! Blog post tutorials are actually better for JMLR submission than videos in many ways.

Why Blog Posts > Videos for JMLR:

1. Easier to Create
    • Write in 2-4 hours vs 12+ hours for videos
    • No recording/editing equipment needed
    • Easy to update/fix mistakes
    • Copy-paste code directly
2. Better for Reviewers
    • Reviewers can skim/scan quickly
    • Code is copy-pasteable (videos require typing)
    • Can Ctrl+F to find specific parts
    • Easier to reference in reviews
3. More Academic
    • Written tutorials are standard in ML papers
    • JMLR encourages online appendices with demonstrations and source code instructions Transactions on Machine Learning Research
    • Fits better with paper format
    • Searchable/indexable
4. Faster for Users
    • 5 min to read vs 25 min to watch
    • Can skip to relevant sections
    • Works without sound/bandwidth
    • Accessible (screen readers, translations)
