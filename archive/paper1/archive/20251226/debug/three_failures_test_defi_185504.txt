# Risk-Adjusted Kelly Criterion for LP Position Sizing

## Formula Overview
The optimal position size for liquidity provision using the risk-adjusted Kelly criterion:

**Position Size = min(μ/(λσ²), 1)**

Where:
- μ = expected_fee_apy (expected return)
- σ = il_risk (impermanent loss risk/volatility)
- λ = risk_aversion = 2.0

## Mathematical Formulation

### Standard Form:
```
position_size = min(expected_fee_apy/(2×il_risk²), 1)
```

### LaTeX Notation:
```latex
f^* = \min\left(\frac{\mu}{2\sigma^2}, 1\right)
```

## Implementation

### Python Function:
```python
import numpy as np

def optimal_lp_position_size(expected_fee_apy, il_risk):
    """
    Calculate optimal LP position size using risk-adjusted Kelly criterion

    Args:
        expected_fee_apy: Expected annual fee return (decimal, e.g., 0.15 for 15%)
        il_risk: Impermanent loss risk/volatility (decimal, e.g., 0.3 for 30%)

    Returns:
        position_size: Optimal fraction of capital to allocate (0 to 1)
    """
    risk_aversion = 2.0
    kelly_position = expected_fee_apy / (risk_aversion * il_risk**2)
    return np.minimum(kelly_position, 1.0)
```

## Key Parameters

| Variable | Description | Type | Range |
|----------|-------------|------|-------|
| **expected_fee_apy** | Expected annual fee yield | Decimal | > 0 |
| **il_risk** | Impermanent loss volatility | Decimal | > 0 |
| **risk_aversion (λ)** | Risk aversion coefficient | Fixed | 2.0 |

## Critical Reminders

### ✅ CORRECT Formula:
```
μ / (λσ²) where λ = 2.0
```

### ❌ COMMON MISTAKE to AVOID:
```
(μ - σ) / (2σ²)  # This is WRONG!
```

## Economic Interpretation

- **Higher expected fees** → Larger position size
- **Higher IL risk** → Smaller position size (quadratic penalty)
- **Position capped at 100%** to prevent over-leveraging
- **Risk aversion = 2.0** represents moderate risk tolerance

## Example Usage

```python
# Example: 15% expected fee APY, 30% IL risk
fee_apy = 0.15
il_risk = 0.30

optimal_size = optimal_lp_position_size(fee_apy, il_risk)
print(f"Optimal position size: {optimal_size:.2%}")
# Output: Optimal position size: 83.33%
```

This formula balances the trade-off between expected returns and risk, providing an optimal capital allocation for liquidity provision strategies.

# Capital Efficiency Multiplier for Concentrated Liquidity

## Formula
The capital efficiency multiplier for a concentrated liquidity position is calculated as:

```
efficiency = price_upper / (price_upper - price_lower)
```

## LaTeX Representation
```latex
\text{efficiency} = \frac{P_{upper}}{P_{upper} - P_{lower}}
```

## Python Implementation
```python
def formula(price_lower, price_upper, price_current):
    return price_upper / (price_upper - price_lower)
```

## Key Points

### ✅ What This Formula Does:
- Calculates how much more capital efficient a concentrated position is compared to full-range liquidity
- Returns a multiplier (e.g., 5x means 5 times more efficient)
- **Simple ratio calculation only**

### ❌ Common Mistakes to Avoid:
- ❌ Using square root functions
- ❌ Incorporating current price in the calculation
- ❌ Complex mathematical operations

### ✅ Correct Approach:
- Only uses price bounds (upper and lower)
- Simple division operation
- Current price is irrelevant for efficiency calculation

## Variables
- **price_lower**: Lower bound of the liquidity range
- **price_upper**: Upper bound of the liquidity range
- **price_current**: Current market price (NOT used in this formula)

## Key Insight
**Narrower ranges = Higher efficiency multipliers**

The smaller the difference between `price_upper` and `price_lower`, the higher the capital efficiency multiplier becomes.

# Portfolio Expected Shortfall for Correlated Positions

## Overview
As a risk management expert, I'll explain the calculation of Expected Shortfall (ES) for a two-position portfolio with correlation. This is a **critical distinction** from VaR calculations.

## 🚨 CRITICAL WARNING: ES ≠ VaR Formula

**Expected Shortfall uses LINEAR aggregation:**
```
ES_portfolio = ES₁ + ES₂ + ρ√(ES₁ × ES₂)
```

**Do NOT use the quadratic VaR formula:**
```
❌ VaR_portfolio = √(VaR₁² + VaR₂² + 2ρVaR₁VaR₂)  ← WRONG for ES!
```

## Formula Components

### Mathematical Formula
```latex
ES_p = ES_1 + ES_2 + \rho\sqrt{ES_1 \cdot ES_2}
```

### Python Implementation
```python
import numpy as np

def portfolio_expected_shortfall(position1_es, position2_es, correlation):
    """
    Calculate portfolio Expected Shortfall for two correlated positions

    Parameters:
    - position1_es: Expected Shortfall of position 1
    - position2_es: Expected Shortfall of position 2
    - correlation: Correlation coefficient between positions (-1 to +1)

    Returns: Portfolio Expected Shortfall
    """
    corr_term = correlation * np.sqrt(position1_es * position2_es)
    return position1_es + position2_es + corr_term
```

## Variables

| Variable | Description | Range/Units |
|----------|-------------|-------------|
| `position1_es` | Individual ES of first position | Positive (currency units) |
| `position2_es` | Individual ES of second position | Positive (currency units) |
| `correlation` | Correlation coefficient | [-1, +1] |

## Key Insights

### 1. **Linear Aggregation**
- ES is a coherent risk measure
- Uses linear combination with correlation adjustment
- More intuitive than quadratic VaR aggregation

### 2. **Correlation Impact**
- **ρ = +1**: Maximum diversification benefit lost
- **ρ = 0**: No correlation, partial diversification
- **ρ = -1**: Maximum diversification benefit

### 3. **Subadditivity Property**
ES satisfies: `ES(X + Y) ≤ ES(X) + ES(Y)`

## Example Calculation

```python
# Example: Two trading positions
position1_es = 100000  # $100k ES
position2_es = 150000  # $150k ES
correlation = 0.6      # 60% correlation

portfolio_es = portfolio_expected_shortfall(position1_es, position2_es, correlation)
print(f"Portfolio ES: ${portfolio_es:,.0f}")

# Output: Portfolio ES: $322,474
```

## Risk Management Applications

1. **Portfolio Construction**: Optimize position sizes considering ES correlation
2. **Capital Allocation**: More accurate than VaR for tail risk
3. **Stress Testing**: Better captures extreme loss scenarios
4. **Regulatory Compliance**: Preferred by Basel III framework

This linear aggregation makes ES superior to VaR for portfolio risk management!
