🧠 Layer 1: LLM-Guided Discovery ⭐ PRIMARY PATH 5-10s
✅ Phase 1: Data Pattern Analysis (0.5s)
• Tests: linearity, polynomial, power law, exponential, logarithmic
• Computes correlations, complexity estimation
• Generates rich context for LLM
✅ Phase 2: LLM Hypothesis Generation (5s)
• Sends patterns + domain knowledge to Claude/GPT
• Requests 5 candidate equations with reasoning
• Example: "This is kinetic energy: KE = 0.5*m*v²"
• LLM has seen millions of equations in training
✅ Phase 3: Rapid Verification + Validation (2-3s)
• Fits coefficients using least squares
• Computes R² score for accuracy
• Runs full 4-layer validation (dimensional + domain + ensemble)
• Ranks hypotheses: 70% R² + 30% validation score
• Success requires: R² > 0.95 AND validation > 70
⚠️ Phase 4: PySR Fallback (if needed, 30s)
• Triggers only if R² < 95% OR validation < 70
• Warm-started from best LLM hypothesis
• Used in 5-20% of cases
🔬 Layer 2: Formal Axiom Reasoning 2-5s
Prove equations from first principles (no data needed)
• Axiom-based construction using formal logic
• Example: Derive KE from F=ma, W=∫F·dx, kinematics
• Confidence: 1.0 (mathematically proven)
• Used when: axioms provided but no data available
• Opens new domains: pure math, theoretical physics
🧬 Layer 3: Symbolic Regression Fallback 30-180s
PySR genetic programming (full search)
• Only used when LLM fails (5-20% of cases)
• Warm-started from LLM's best hypothesis
• Explores full equation space
• Slower but comprehensive
✅ Layer 4: Complete 4-Layer Validation 1-2s
Ensemble validation (from System 2)
• Symbolic validation (30%) - expression complexity
• Dimensional analysis (30%) - unit consistency
• Domain validation (30%) - physical constraints
• Numerical stability (10%) - computation safety
Dual threshold: R² > 0.95 AND validation > 70
