MANUSCRIPT MERGE - QUICK REFERENCE CARD
========================================

LOCATION
--------
papers/2025-JMLR/

FILES
-----
Original:     paper/jmlr_paper.tex
Alternative:  supplementaries/manuscript/hypatiax_manuscript.tex
Working Copy: paper/jmlr_paper_MERGED.tex (you'll create this)


QUICK START
-----------
cd papers/2025-JMLR/paper/
cp jmlr_paper.tex jmlr_paper_MERGED.tex
# Now edit jmlr_paper_MERGED.tex


MERGE STRATEGY
--------------
Section              | Recommendation
---------------------|--------------------------------
Abstract             | Merge both (keep clarity, add depth)
Introduction         | Use alternative (more detailed)
Architecture         | Use alternative (6 pages vs 3)
Methods              | Merge both experiments
Results              | CAREFULLY merge (no duplication)
Discussion           | Use alternative (6 pages vs 3)
Conclusion           | Merge future work from both
Bibliography         | Combine and deduplicate


ESSENTIAL COMMANDS
------------------
# Test compilation:
pdflatex jmlr_paper_MERGED.tex

# Full build:
pdflatex jmlr_paper_MERGED.tex && bibtex jmlr_paper_MERGED && pdflatex jmlr_paper_MERGED.tex && pdflatex jmlr_paper_MERGED.tex

# Check for errors:
grep "Error" jmlr_paper_MERGED.log

# Merge bibliographies:
cat references.bib supplementaries/manuscript/Bib/bibliography.bib | python3 ../../latex/Bib/deduplication_bib.py > references_new.bib

# Count pages:
pdfinfo jmlr_paper_MERGED.pdf | grep Pages


COMMON ISSUES & FIXES
---------------------
Issue: LaTeX error "Undefined control sequence"
Fix: Check for missing packages in preamble

Issue: Figures not appearing
Fix: Check paths - may need ../figures/ prefix

Issue: Bibliography not resolving
Fix: Run bibtex, then pdflatex twice more

Issue: "??" in PDF
Fix: References not resolving - check citation keys


EDITING WORKFLOW
----------------
1. Open both PDFs side-by-side:
   - jmlr_paper.pdf (original)
   - supplementaries/manuscript/hypatiax_manuscript.pdf (if compiled)

2. Open jmlr_paper_MERGED.tex in your editor

3. For each section:
   - Compare both versions
   - Copy better content to MERGED.tex
   - Avoid duplication
   - Test compile frequently

4. Save often, test often
