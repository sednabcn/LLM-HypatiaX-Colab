KEY PRINCIPLES
==============

1. SELF-CONTAINED: Each paper directory has everything needed to reproduce results
2. ISOLATED: Changes to one paper don't affect others
3. VERSIONED: Each paper can have different code/data versions
4. REPRODUCIBLE: Complete workflow from data to paper


WORKFLOW
========

1. Create Paper:       ./create_new_paper.sh 2026-NeurIPS
2. Add Code:           cp your_code.py 2026-NeurIPS/experiments/hypatiax/core/
3. Add Data:           cp your_data.csv 2026-NeurIPS/experiments/hypatiax/data/
4. Run Experiments:    cd 2026-NeurIPS/experiments/hypatiax && python core/training/...
5. Generate Figures:   cd 2026-NeurIPS/src && python plot_results.py
6. Build Paper:        cd 2026-NeurIPS/scripts && ./build.sh


MANAGING MULTIPLE PAPERS
=========================

papers/2025-JMLR/experiments/hypatiax/      # JMLR-specific experiments
papers/2026-NeurIPS/experiments/hypatiax/   # NeurIPS-specific experiments
papers/2026-ICML/experiments/hypatiax/      # ICML-specific experiments

Each paper has its own independent experimental codebase!
